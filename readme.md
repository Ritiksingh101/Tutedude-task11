# create a responsive web page  

## Project Description

 a simple "css web page" web page built using basic HTML5. The goal of this project was to learn the fundamental structure of an HTML document, including the use of `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, and `<body>` tags.

The project consists of a Two file: `index.html`, `product.html`, `cart.html`, `payment.html` and `style.css`
